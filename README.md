# Art of Healthy Baking – The Cake Box

High-converting, responsive landing page for **The Cake Box** (Art of Healthy Baking Complete Masterclass in Tamil).

## 🍰 Features
- **Clean Luxury Design:** Pastel color palette inspired by the multi-layered cake brand logo (Rose Pink, Mint Teal, Buttercream Champagne & Plum).
- **11 Comprehensive Modules:** 35+ healthy recipes (brownies, sourdough/whole wheat breads, pizza, muffins, cookies, healthy spreads).
- **Equipment Guide:** Interactive tabs for essential baking gear with brand recommendations.
- **Topic-Wise Custom Calculator:** Interactive module selector building custom WhatsApp enquiry messages dynamically.
- **Live Urgency:** Dynamic ticking countdown timer for upcoming batch admissions.
- **WhatsApp Direct Integration:** Fast customer inquiries connected to Mentor Sathika & Manisha (+91 7200823014).
- **100% Vanilla Tech:** Pure HTML5, Vanilla CSS3, and ES6 JavaScript (zero external framework bloat).

## 🚀 How to Run Locally
Open `index.html` directly in any web browser, or run a local web server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve .
```

## 🌐 Deploying to GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your website will be live worldwide in seconds!
